Setup Instructions

  1. Go to Azure Portal - App Registrations
  2. Create a new registration or select existing
  3. Copy the Application (client) ID and Directory (tenant) ID
  4. Go to Certificates & secrets and create a new client secret
  5. Go to Authentication and add Redirect URI: {{ .Provider.RedirectURL }}
  6. Go to API permissions and add:
    • User.Read (Delegated)
    • Directory.Read.All (Application)
  7. Click "Grant admin consent" for the permissions
  8. Enter the values above and click Save
